# Sobre Etnias — site multipáginas

## Como executar
1. Extraia o ZIP.
2. Abra esta pasta no Visual Studio Code.
3. Instale a extensão **Live Server**.
4. Clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Páginas
- `index.html`: início
- `protagonismo.html`: Protagonismo e História
- `cultura.html`: Cultura e Conhecimento
- `glossario.html`: Aprendizado · Glossário
- `quiz.html`: Quiz

Cada item do menu abre uma página HTML independente. Todas compartilham `style.css` e `script.js` para manter o mesmo visual e os recursos interativos.
